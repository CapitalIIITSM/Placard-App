# C3SKELX DIY Placard Webapp

## 📦 What's Included

This folder contains everything you need to generate professional placards and hotel signs for Capital III, Seat King, and Electrex.

### Files:
- `placard-generator.html` - The main webapp (open this file)
- 10 SVG template files (C3S_*.svg, SK_*.svg, ELX_*.svg, C3SKELX_*.svg)
- 8 font files (.ttf, .otf, .woff2)

## 🚀 How to Use

### Option 1: Simple Local Use
1. **Download this entire folder** to your computer
2. **Keep all files together** in the same folder (don't move anything)
3. **Double-click `placard-generator.html`** to open in your web browser
4. Select a template, enter text, and generate your placard!

### Option 2: Local Web Server (Recommended)
If you see errors about loading files, you may need to run a local web server:

**On Mac/Linux:**
1. Open Terminal
2. Navigate to this folder: `cd /path/to/this/folder`
3. Run: `python3 -m http.server 8000`
4. Open browser to: `http://localhost:8000/placard-generator.html`

**On Windows:**
1. Open Command Prompt
2. Navigate to this folder: `cd C:\path\to\this\folder`
3. Run: `python -m http.server 8000`
4. Open browser to: `http://localhost:8000/placard-generator.html`

## 💾 Saving Your Work

**Save JPEG:** Downloads a 300 DPI, 8.5" × 11" print-ready file
**Print:** Opens your browser's print dialog for immediate printing

## ❓ Troubleshooting

### "Template file not found" error
- Make sure ALL files from this folder are in the same directory
- Don't rename any files
- Try using a local web server (see Option 2 above)

### Fonts don't look right
- Make sure all font files (.ttf, .otf, .woff2) are in the same folder
- Try refreshing the page (Ctrl+R or Cmd+R)

### Browser compatibility
- Works best in Chrome, Firefox, Safari, or Edge
- Requires a modern browser (2020 or newer)

## 📝 Notes

- **Hotel signs** don't have editable fields - they're ready to print as-is
- **Employee placards** have fields for Name and Job Title
- **SK names** automatically convert to uppercase (brand standard)
- Text automatically scales down if it's too long to fit

- Output: 2550 × 3300 pixels (8.5" × 11" at 300 DPI)
